# Array, object, class demos
There are five basic demos of key data structures: array, object,  object with methods, class and array of objects

1. **array.js** shows how to declare, update, add and remove data
2. **objects.js** shows a basic object storing fields of data about a laptop. The demo shows access, output, add fields to and remove from
3. **methods.js** shows a basic object but with functions in the defined object and how the functions and data are accessed
4. **class.js** shows a basic class with the same example as the object but with a constructor and private fields
5. **array-of-objs** shows some basic objects in an array and how to access their fields
